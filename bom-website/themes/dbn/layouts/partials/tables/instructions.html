How to use this table

Use the main tabs to switch between Weekly Data (detailed week-by-week records) and Annual Data (yearly summaries). Each main tab has secondary tabs to view data organized By Parish, By Cause of Death, or By Christening.

Click the Filters button to refine your data by parishes, years, and count types. You can search parishes by typing in the search box, and select multiple options from each filter category.

You can click on an individual row to view additional information.

When data is missing from the original records, empty count values are displayed as - to indicate unavailable data. Similarly, records marked as missing or illegible in our dataset will show missing data or illegible data labels in the detailed view.
